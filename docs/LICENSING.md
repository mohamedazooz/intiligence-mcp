# Licensing and Supply Chain

Three modes differ: separate service via API, dependency/SDK, or copying/forking source. Review each mode separately.

- Firecrawl, SearXNG and MISP: AGPL-3.0 review before embedding or redistribution.
- n8n: Sustainable Use License; hosted/commercial product model needs terms review.
- OpenCTI: distinguish community repository from enterprise components.
- Official MCP servers: license can differ by package.
- ProjectDiscovery: inspect each repository independently.

Record SPDX identifier, LICENSE hash, upstream commit, copyright notices, transitive SBOM and counsel decision. Pin versions and scan dependencies before running install scripts.
